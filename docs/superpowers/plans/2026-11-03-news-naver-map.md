# 게시글 네이버 지도 구현 계획

## 승인된 명세

- `docs/superpowers/specs/2026-11-03-news-naver-map-design.md`

## 작업 1: 지도 링크 계약과 데이터 저장

- 네이버 길찾기 URL 파서와 서버 입력 검증을 추가한다.
- `CoopNews`, `FreePost`에 구조화된 지도 필드와 마이그레이션을 추가한다.
- 공지·자유게시판 목록 직렬화와 등록·수정 API에 지도 필드를 연결한다.
- 파서, API 페이로드, 목록 매핑 테스트를 추가한다.

## 작업 2: 공용 네이버 지도 컴포넌트

- 기존 조합소개 지도 로더와 충돌하지 않는 SDK 로더를 만든다.
- 링크 입력, 목적지 인식, 위치 확인, 제거를 지원하는 지도 필드를 만든다.
- 저장된 위치를 표시하는 반응형 게시글 지도 카드를 만든다.
- API 키 누락·로딩 실패·잘못된 링크 상태를 사실대로 표시한다.

## 작업 3: 자유게시판과 공지사항 연결

- 자유게시판 등록·수정·열람에 지도 필드와 카드를 연결한다.
- 공지사항 등록·수정·열람에 같은 지도 필드와 카드를 연결한다.
- 기존 유튜브, 첨부파일, 공개 범위, 댓글 기능을 유지한다.
- 컴포넌트 테스트로 등록·수정 페이로드와 열람 표시를 검증한다.

## 작업 4: 검증과 UI 리뷰

- 지도 관련 집중 테스트를 실행한다.
- `pnpm lint`, `pnpm test`, `pnpm build`, `git diff --check`를 실행한다.
- 실행 중인 페이지를 데스크톱과 모바일에서 확인한다.
- `dbapt-site-ui-review` 결과를 `PASS`로 기록한다.
- 지도 기능 파일만 명시적으로 스테이징해 커밋·푸시한다.
