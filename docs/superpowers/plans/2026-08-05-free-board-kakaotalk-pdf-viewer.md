# 자유게시판 카카오톡 PDF 온라인 열람

## Goal

카카오톡 인앱 브라우저에서 자유게시판 첨부 PDF를 다운로드 화면으로 이탈하지 않고 홈페이지 안에서 페이지별로 열람할 수 있게 한다.

## Approved Scope

- PDF 첨부는 `PDF 바로 보기`와 `다운로드`를 분리한다.
- 공개 공유가 허용된 글은 비로그인 공유 수신자도 첨부를 열람할 수 있다.
- 비공개 글은 기존 로그인 경계를 유지한다.
- Supabase 공개 URL을 클라이언트가 직접 열지 않고 서버가 허용된 버킷 경로만 검증해 제공한다.
- PDF.js로 한 번에 한 페이지만 렌더링하고 페이지 이동, 확대·축소, 로딩률, 재시도, 원본 다운로드를 제공한다.
- 한글·오피스·ZIP 파일은 온라인 미리보기 없이 다운로드만 제공한다.

## Verification

- 저장소 URL 검증, 공개/로그인 접근, inline/download 응답 헤더 테스트
- 자유게시판 첨부 버튼 회귀 테스트
- 전체 lint, test, production build
- Chrome 390x844에서 실제 공개 공유 PDF의 첫 페이지, 다음 페이지, 가로 넘침 확인
