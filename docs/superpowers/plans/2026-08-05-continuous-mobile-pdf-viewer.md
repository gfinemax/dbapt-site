# Continuous Mobile PDF Viewer Implementation Plan

## Goal

카카오톡 인앱 브라우저에서도 원본 PDF 다운로드를 시작하지 않고, 브라우저 기본 PDF 뷰어와 유사한 연속 열람 경험을 사이트 안에서 제공한다.

## Implementation

1. PDF 문서는 상세 정보 카드가 아닌 PDF 전용 전체 화면으로 바로 열고, `문서 정보`를 선택할 때만 상세 화면으로 전환한다.
2. 공통 `PdfCanvasViewer`가 모든 PDF 페이지를 세로로 이어 표시한다.
3. 현재 화면과 가까운 페이지만 PDF.js 캔버스로 렌더링하고 먼 페이지는 크기 유지 placeholder로 교체한다.
4. 현재 페이지를 스크롤 위치와 동기화하고 이전·다음 및 페이지 번호 직접 이동을 제공한다.
5. 확대·축소 버튼, 화면 너비 맞춤, 상한 없는 모바일 두 손가락 확대·축소를 제공한다. 제스처 중에는 CSS 확대와 손가락 중심점 스크롤 보정만 수행하고, 제스처 종료 시 한 번만 캔버스를 다시 렌더링한다.
6. 문서 모달과 자유게시판 PDF 화면이 기존 공통 뷰어를 그대로 사용하도록 유지한다.

## Safety Boundaries

- 보기·다운로드 API, 세션 권한, 감사 로그 정책은 변경하지 않는다.
- 다운로드는 기존 명시적 다운로드 버튼과 확인 절차에서만 시작한다.
- PDF 원본을 `iframe`이나 브라우저 PDF URL로 직접 열지 않는다.

- 관련 PDF 모달 회귀 테스트
