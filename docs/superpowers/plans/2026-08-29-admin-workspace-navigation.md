# 운영자 워크스페이스 내비게이션 구현 계획

## 작업 순서

1. 운영자 공통 레이아웃 셸과 관리자 라우트 레이아웃을 추가한다.
2. 기존 운영자 사이드바가 독립 라우트에서도 실제 목적지로 이동하고 현재 위치를 표시하게 한다.
3. `운영자 홈`과 `사이트 홈`을 분리하고 사이드바의 `새 문서 등록`을 제거한다.
4. 관리자 포털 본문을 공통 셸 안에서 중복 헤더 없이 렌더링하고 역할 문구를 수정한다.
5. 데스크톱·모바일 내비게이션과 기존 저장·검색·감사 기능의 회귀 테스트를 실행한다.
6. UI 리뷰와 전체 lint, test, build, 브라우저 검증을 완료한다.

## 구현 경계

- 인증된 ADMIN에게만 공통 운영자 셸을 노출한다.
- 기존 관리자 데이터 조회·저장 로직은 변경하지 않는다.
- 조합원 및 환불조합원 내비게이션 계약은 유지한다.
- 공개 페이지에서 열리는 기존 운영자 드로어도 동일한 목적지 계약을 사용한다.
