# 카카오톡 문서 PDF 온라인 열람 개선 계획

## 목표

- 카카오톡 인앱 브라우저에서 PDF 크기와 관계없이 다운로드 안내 없이 문서를 온라인으로 열람한다.
- 다운로드는 사용자가 버튼을 누르고 확인한 뒤에만 시작한다.
- 기존 문서 권한 검증과 VIEW/DOWNLOAD 감사 로그 경계를 유지한다.

## 구현 범위

1. 브라우저 내장 PDF iframe을 PDF.js 캔버스 뷰어로 교체한다.
2. 본문, 통합 PDF, 추가 PDF 첨부 모두 같은 온라인 뷰어를 사용한다.
3. 문서 및 첨부 다운로드 버튼에 파일명·크기·모바일 데이터 안내 확인창을 추가한다.
4. 취소 시 다운로드 API를 호출하지 않고, 확인 시 기존 다운로드 API를 한 번 호출한다.
5. 자유게시판 PDF 뷰어도 공통 캔버스 뷰어와 동일한 다운로드 확인 흐름을 사용한다.

## 제외 범위

- 저장소와 DB 스키마 변경
- 문서 권한 및 감사 로그 정책 변경
- PDF 원본 또는 최적화 정책 변경

## 검증

- 모달 단위 테스트: iframe 부재, view URL, 다운로드 확인/취소/실행, 관련 문서 전환
- 전체 `pnpm lint`, `pnpm test`, `pnpm build`
- 데스크톱과 모바일 너비에서 실제 PDF 렌더링, 페이지 이동, 확대/축소, 다운로드 확인창 검증
