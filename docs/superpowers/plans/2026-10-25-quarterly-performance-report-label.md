# 분기실적보고서(조합) 표시명 변경 계획

## Goal

공개자료 문서함의 기존 `실적보고서` 저장값과 필터 호환성을 유지하면서 사용자에게는 `분기실적보고서(조합)`으로 표시한다.

## Tasks

1. 공용 표시명 변환 함수를 추가한다.
2. 공개자료 내비게이션, 카드·문서함, 필터, 등록·수정 폼에서 새 표시명을 사용한다.
3. 기존 `실적보고서`와 `추진실적` 자료가 동일한 문서함에서 계속 조회되는지 집중 테스트한다.
4. 린트, 전체 테스트, 빌드 및 데스크톱·모바일 화면을 검증한다.
5. UI 리뷰 결과와 최종 검증 근거를 기록한다.

## Out Of Scope

- 데이터베이스의 기존 `subCategory` 값 변경
- 개별 문서 제목 변경
- 공개 범위, 권한, 문서 작업 변경
