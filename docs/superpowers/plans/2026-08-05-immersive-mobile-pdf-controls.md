# Immersive Mobile PDF Controls

1. 자유게시판 PDF 문서 정보 영역을 콘텐츠 위 오버레이로 전환하고 1.8초 뒤 자동으로 숨긴다.
2. 공통 PDF 페이지·배율 도구를 오버레이로 전환하고 스크롤·핀치 중 숨기며 화면 탭으로 다시 표시한다.
3. 사용자 동작에서 Fullscreen API를 호출하고 차단되면 고정형 인페이지 몰입 모드를 사용한다.
4. 가로 화면에서 PDF가 화면 전체 폭과 높이를 사용하도록 외곽 여백과 둥근 테두리를 제거한다.
5. 자동 숨김, 탭 재표시, 네이티브 전체화면, 대체 모드 테스트 후 lint, test, build와 모바일 화면 검증을 수행한다.
6. 가로 화면에서는 일반 메뉴와 PDF 도구를 잠그고 `× 열람 종료`와 최초 안내만 유지한다.
7. 종료 버튼, 안드로이드 뒤로가기, 세로 회전으로 기존 상단 메뉴와 PDF 도구를 복원한다.
