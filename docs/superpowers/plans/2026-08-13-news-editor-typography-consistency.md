# 게시판 편집기 타이포그래피 일관성 구현 계획

1. 1px 글자 크기, 줄간격, 문단 간격의 정상·경계·위험 값 sanitizer 테스트를 추가한다.
2. 공용 타이포그래피 값 검증과 기본값을 구현한다.
3. Tiptap 글자 크기와 문단 서식 extension을 확장하고 현재 선택 영역/문단에 적용한다.
4. 숫자 입력과 빠른 선택을 결합한 모바일 대응 툴바 그룹을 구현한다.
5. 편집·조회 공통 fallback을 14px/1.6/12px로 통일하고 기존 명시값을 보존한다.
6. 공지·자유게시판 작성/수정/조회 회귀 테스트를 수행한다.
7. `pnpm lint`, `pnpm test`, `pnpm build` 및 데스크톱·모바일 UI 검증을 수행한다.
