# 계정 찾기 및 수동 문자 비밀번호 재설정 설계

작성일: 2026-09-24
상태: 사용자 승인 완료

## 1. 목표

조합원이 로그인 아이디 또는 비밀번호를 잊었을 때 로그인 화면에서 도움을 요청하고, 관리자가 기존 회원가입 승인 흐름과 유사하게 요청을 확인한 뒤 사무국 전용 휴대전화 또는 관리자 개인 휴대전화의 문자 앱으로 안내를 전달할 수 있게 한다.

외부 알림톡·문자 API 계약 없이 운영하며, 사이트는 문자를 자동 발송했다고 주장하지 않는다. 실제 문자 발송은 관리자가 휴대전화의 문자 앱에서 최종 확인하고 실행한다.

## 2. 사용자 흐름

1. 로그인 화면에서 `아이디 찾기` 또는 `비밀번호 재설정`을 선택한다.
2. 사용자는 이름과 사이트에 등록한 휴대전화 번호를 입력한다.
3. 사이트는 이름과 휴대전화 번호가 정확히 일치하는 활성 계정을 찾되, 성공 여부와 계정 존재 여부를 공개 화면에 노출하지 않는다.
4. 일치하는 계정이 하나일 때 관리자용 계정 복구 요청을 생성한다.
5. 사용자에게는 사무국 확인 후 등록된 연락처로 안내한다는 동일한 문구를 보여준다.

## 3. 관리자 흐름

1. `계정 복구 요청` 화면에서 대기 요청을 확인한다.
2. 요청 대상은 내부 사용자 ID로 고정하고 이름만으로 다시 매칭하지 않는다.
3. 관리자는 `사무국 전용폰` 또는 `관리자 개인폰`을 선택한다.
4. 아이디 찾기 요청은 등록된 로그인 아이디가 포함된 안내 문구를 생성한다.
5. 비밀번호 재설정 요청은 12시간 동안 한 번만 사용할 수 있는 링크와 안내 문구를 생성한다.
6. 모바일에서는 `문자 앱 열기`, 모든 환경에서는 `문구 복사`를 제공한다.
7. 관리자가 실제 전송 후 `발송 완료`를 기록한다.
8. 개인폰을 선택하면 개인번호가 회원에게 공개된다는 경고를 표시한다.

사이트는 관리자 개인 휴대전화 번호를 저장하지 않는다. 감사 기록에는 발송 수단 구분, 처리 관리자, 처리 시각만 남긴다.

## 4. 재설정 링크 보안

- 원본 토큰은 생성 직후 관리자 화면에 한 번 반환하며 DB에는 SHA-256 해시만 저장한다.
- 링크는 생성 후 12시간 동안 유효하고 한 번만 사용할 수 있다.
- 같은 사용자에게 새 링크를 발급하면 이전 미사용 링크는 즉시 폐기한다.
- 사용 완료, 취소, 만료된 링크는 사용할 수 없다.
- 새 비밀번호는 현재 사이트의 승인된 사용자 비밀번호 규칙을 적용한다.
- 비밀번호 변경 후 사용자의 인증 버전을 증가시켜 기존 JWT 세션을 무효화한다.
- Google 전용 계정에는 사이트 비밀번호 재설정 링크를 만들지 않고 Google 로그인을 안내한다.

## 5. 개인정보 및 열거 방지

- 공개 화면은 계정 존재 여부, 아이디, 휴대전화 일부 또는 역할을 노출하지 않는다.
- 이름만으로 계정을 찾지 않는다.
- 중복 후보가 있으면 자동 연결하거나 요청을 생성하지 않는다.
- 짧은 시간 안의 중복 요청은 하나로 합치고 과도한 요청을 제한한다.
- 관리자 화면에는 업무에 필요한 최소한의 회원 정보만 표시한다.
- 비밀번호, 원본 토큰, 관리자 개인번호는 감사 기록이나 로그에 저장하지 않는다.

## 6. 상태와 감사 기록

요청 상태는 다음 값을 사용한다.

- `PENDING`: 관리자 확인 대기
- `LINK_CREATED`: 재설정 링크 생성
- `SENT`: 관리자가 문자 발송 완료로 표시
- `COMPLETED`: 아이디 안내 완료 또는 비밀번호 변경 완료
- `CANCELLED`: 관리자 취소 또는 새 링크 발급에 따른 이전 요청 폐기
- `EXPIRED`: 유효시간 만료

각 요청에는 요청 유형, 대상 사용자 ID, 처리 관리자 ID, 발송 수단, 링크 생성·발송·완료 시각을 보존한다.

## 7. 범위 제외

- 카카오 알림톡 또는 SMS API 자동 발송
- 관리자 개인 휴대전화 번호 저장
- 기존 비밀번호 조회 또는 평문 저장
- 관리자에 의한 새 비밀번호 직접 지정
- 이름만으로 계정 자동 연결
- 비밀번호 정책 자체 변경

## 8. 승인 근거

사용자는 2026-09-24 대화에서 사무국 전용 휴대전화와 관리자 개인 휴대전화를 상황에 따라 선택하고, 관리자 모드에서 수동 문자로 12시간 일회용 링크를 전달하는 방식을 승인하고 구현을 요청했다.
