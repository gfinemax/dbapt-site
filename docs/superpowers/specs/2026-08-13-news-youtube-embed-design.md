# 게시판 유튜브 영상 재생 설계

## 승인 범위

- 공지사항과 자유게시판 게시글에 선택적인 유튜브 주소 하나를 저장한다.
- `youtube.com/watch`, `youtu.be`, `youtube.com/shorts`, `youtube.com/embed` 주소에서 유효한 영상 ID만 추출한다.
- 게시글 상세에서 `youtube-nocookie.com` 기반 반응형 플레이어로 재생한다.
- 공지 작성·수정은 기존 관리자 권한을, 자유게시판 작성·수정은 기존 로그인·작성자 권한을 그대로 따른다.

## 제외 범위

- 영상 파일 직접 업로드, 외부 플랫폼 API 연동, 영상 메타데이터 조회, 자동 자막·인코딩, 복수 영상 갤러리.

## 데이터 및 안전성

- 원본 URL 대신 검증된 11자 유튜브 영상 ID만 저장한다.
- 임의 iframe HTML은 허용하지 않는다.
- 빈 입력은 영상을 제거한다.
