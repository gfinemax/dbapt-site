# 조합원 개인정보 수정·이력 관리 설계

작성일: 2026-08-23
상태: 사용자 승인

## 목표

로그인한 조합원이 자신의 개인정보를 확인하고 항목별 정정을 요청하며, 관리자 승인과 홈페이지·PeopleON 반영 상태를 날짜와 함께 추적한다.

## 범위

- 이름, 휴대전화, 이메일, 주소, 우편 수령지, 생년월일, 공동명의 정보, 환불계좌, 알림 설정, 신청 평형, 동·호수, 조합원 자격의 수정 요청
- 신청 평형·동호수·조합원 자격은 원장 정정 요청으로만 처리
- 변경 전·후 값, 요청일, 처리일, 요청자, 처리자, 공개 메모, 관리자 메모, 상태 이벤트 보존
- 사용자 본인 이력과 관리자 처리 목록
- PeopleON 고유 ID 사용 및 수동 반영 상태 추적
- 민감정보 마스킹과 역할 기반 접근 통제

## 제외 범위

- 주민등록번호 저장
- 이름 기반 자동 매칭
- OTP가 없는 휴대전화 즉시 변경
- 지원 계약이 확인되지 않은 PeopleON 쓰기 API 호출
- 변경 이력 삭제

## 정책

- 모든 수정은 변경 요청으로 시작한다.
- 관리자가 승인한 요청만 홈페이지 프로필에 반영한다.
- PeopleON은 `NOT_REQUIRED`, `PENDING`, `COMPLETED`, `FAILED` 상태로 홈페이지 반영과 별도로 추적한다.
- 신청 평형은 기존 납부 프로필의 원천값을 직접 덮어쓰지 않는다.
- 환불 조합원에게 신청 평형을 노출하지 않는다.
- 사용자 공개 메모와 관리자 내부 메모를 분리한다.
- 한 사용자의 같은 항목에 처리 중 요청은 하나만 허용한다.

## 완료 기준

- 로그인 사용자는 본인 정보와 최근 변경 이력을 확인하고 수정 요청을 제출할 수 있다.
- 관리자는 요청을 승인·반려하고 PeopleON 반영 상태를 기록할 수 있다.
- 승인 시 현재 프로필과 변경 이벤트가 한 트랜잭션으로 저장된다.
- 민감정보는 사용자·관리자 목록에서 마스킹된다.
- 권한·상태·중복·환불 조합원 규칙이 테스트된다.
