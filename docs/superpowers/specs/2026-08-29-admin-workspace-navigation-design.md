# 운영자 워크스페이스 내비게이션 설계

작성일: 2026-08-29
상태: 사용자 승인 후 구현

## 목표

운영자가 대시보드, 문서 등록, 조합원 관리, 보안 감사 화면 사이를 이동해도 운영자 서비스의 맥락과 복귀 수단을 잃지 않게 한다.

## 범위

- 인증된 ADMIN의 `/portal/admin`과 모든 하위 라우트에 공통 운영자 셸을 제공한다.
- `운영자 홈`은 `/portal/admin`, `사이트 홈`은 `/`로 명확히 구분한다.
- 데스크톱에서는 공통 사이드바, 모바일에서는 공통 상단 복귀·메뉴 동선을 유지한다.
- 관리자 화면의 역할 표기를 `운영자 전용 서비스`로 정리한다.
- `새 문서 등록` 기능은 유지하되 사이드바 독립 메뉴에서는 제거하고 문서 목록의 주 작업 버튼으로 진입한다.
- 문서 등록, 조합원 관리, 보안 감사, 게시판 목적지는 기존 실제 라우트를 재사용한다.
- 현재 관리자 하위 화면에 맞는 메뉴를 표시한다.

## 제외 범위

- 문서 등록·저장 계약 변경
- PeopleOn 쓰기 또는 회원 권한 계약 변경
- 조합원·환불조합원 개인 서비스 메뉴 변경
- 관리자 기능의 공개 내비게이션 노출

## 접근성과 반응형

- 키보드 포커스 표시를 유지한다.
- 모바일에서 운영자 홈과 사이트 홈을 항상 찾을 수 있어야 한다.
- 공통 셸과 본문은 가로 넘침 없이 독립적으로 스크롤되어야 한다.
